# Mel-spectrogram (멜 스펙트로그램)

> [!summary]
> Mel-spectrogram은 오디오 파형을 **시간-주파수 이차원 이미지**로 변환한 표현이다. 사람의 청각 특성(주파수 인지의 비선형성)에 맞게 주파수 축이 조정되어 있어, 음성·음악 처리 AI 모델의 표준 입력 형식으로 쓰인다.

## 핵심 개념

- **변환 과정**: 오디오 파형 → STFT(단시간 푸리에 변환)로 시간-주파수 변환 → 멜 스케일로 주파수 축 변환 → 로그 변환.
- **결과**: 가로축=시간, 세로축=멜 주파수, 색=강도(dB)인 2D 이미지.
- **왜 멜 스케일인가**: 사람 귀는 저주파수 변화에 민감, 고주파수에서는 둔감. 멜 스케일은 이를 반영.
- **이미지 생성 AI와의 연결**: 멜 스펙트로그램은 "이미지"이므로 [[Diffusion]] 같은 이미지 생성 모델을 그대로 음악에 적용 가능 → [[Stable Audio]]의 기반.

## 상세 설명

음악·음성 AI의 발전에서 멜 스펙트로그램은 핵심 가교 역할을 했다. 오디오를 직접 다루는 것보다 멜 스펙트로그램으로 변환해 처리하는 것이 효율적이고, 이미지 도메인의 노하우(CNN·Diffusion 등)를 그대로 끌어올 수 있다.

[[Stable Audio]]는 잠재 멜 스펙트로그램 표현 위에서 디퓨전을 수행한 후 보코더로 다시 파형을 복원한다. [[MusicGen]] 같은 자기회귀 모델은 멜 스펙트로그램 대신 EnCodec 같은 신경 코덱을 쓰지만, 둘 다 "오디오를 압축 표현으로 다룬다"는 공통점이 있다.

강의에서는 깊이 다루지 않지만, "어떻게 AI가 음악을 만드는가?"라는 질문의 기술적 답에 멜 스펙트로그램이 자주 등장한다.

## 예시

- 음성 인식 시스템(Whisper, 음성 비서)의 입력 처리
- [[Stable Audio]]에서 디퓨전이 작동하는 잠재 공간
- 음악 분류·장르 인식 모델의 표준 입력
- AI 보컬 합성에서 텍스트 → 멜 스펙트로그램 → 보코더 → 파형 흐름
