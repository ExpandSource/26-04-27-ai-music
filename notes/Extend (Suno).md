# Extend (Suno)

> [!summary]
> Extend는 [[Suno]]에서 **이미 만든 곡 끝에 이어서 더 길게** 만드는 기능이다. 30초짜리 좋은 인트로를 3분 풀 트랙으로 키우거나, 마음에 드는 분위기를 유지하며 곡 길이를 늘릴 때 사용한다.

## 핵심 개념

- **사용법**: Library의 곡 메뉴 → "Extend" → 어디서 이어 붙일지 선택 → 가사·스타일 입력(선택) → Generate.
- **유지되는 것**: 기존 곡의 분위기·보컬·템포.
- **추가되는 것**: 새 가사·새 구간(브리지·아웃트로 등).
- **크레딧**: 새 곡 생성과 비슷한 [[Credit (Suno)]] 10.
- **곡 길이 한계**: V4.5 무료에서 최대 8분까지 누적 가능.

## 상세 설명

AI 음악 생성은 한 번에 마음에 드는 길이가 나오는 경우가 드물다. Extend는 "30초만 좋아도 그 30초를 기점으로 풀 트랙을 만들 수 있다"는 안전망이다. 강의에서 "한 번에 안 되는 게 정상"이라고 안내한 뒤, Extend로 키우는 흐름을 보여주면 청중의 부담이 줄어든다.

Extend는 새 가사를 추가할 때 **메타 태그**를 적극 활용하는 것이 좋다. `[bridge]`나 `[outro]`를 명시하면 자연스러운 곡 진행을 만든다.

크레딧 절약 팁: 처음부터 풀 길이로 만들기보다 **Simple로 짧게 → Library에서 마음에 드는 것 → Extend로 확장**이 효율적이다.

## 예시

- 30초 인트로 → Extend (with [verse] [chorus]) → 2분 30초 풀 트랙
- 끝이 어색한 곡 → Extend ([outro] 명시) → 자연스러운 마무리
- 좋은 발라드 → Extend ([bridge] 추가) → 변화 구간이 있는 풍부한 버전
