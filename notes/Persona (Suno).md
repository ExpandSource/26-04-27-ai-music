# Persona (Suno)

> [!summary]
> Persona는 [[Suno]]에서 **특정 보컬·스타일을 저장해 여러 곡에 재사용**하는 기능이다. 한 번 마음에 드는 보컬이 나오면 그 목소리를 Persona로 묶어, 다음 곡들에도 같은 가수가 부르는 것처럼 일관성을 유지할 수 있다.

## 핵심 개념

- **만드는 법**: 좋아하는 곡 → 메뉴 → "Create Persona from this" (또는 More Options → Save as Persona).
- **사용법**: Create → Custom 모드 → More Options → 저장된 Persona 선택.
- **저장되는 것**: 보컬 음색·스타일 특성. 가사·장르는 새로 입력 가능.
- **활용 영역**: 시리즈 콘텐츠, 가족 행사 노래 시리즈, 채널 BGM 통일감, 캐릭터 보이스.

## 상세 설명

AI 음악 생성의 큰 약점은 "매번 다른 가수가 부르는 듯한" 보컬의 일관성 부족이었다. Persona는 이 문제를 정면 해결한다. 마치 [[Nano Banana]]의 캐릭터 일관성처럼, 음악에서도 "같은 가수의 시리즈 곡"이 가능해진다.

Persona 생성 자체는 보통 무료지만, Persona를 사용한 곡 생성은 일반 [[Credit (Suno)]]을 소모한다. 강의에서는 시간이 남은 분이 선택 Lab으로 시도. 가족 시리즈("어머니 노래", "아버지 노래", "손녀 노래")에 같은 보컬을 통일하면 감동의 결이 다르다.

유료 플랜에서는 Persona 라이브러리 용량이 늘어나고, 한 곡 안에서 여러 Persona 보컬이 등장하는 듀엣도 가능.

## 예시

- "봄빛처럼" 발라드의 여성 보컬을 "Spring Voice" Persona로 저장
- 다음 곡 "가을 단풍 길" 생성 시 같은 Persona 선택 → 같은 가수가 부르는 가을 노래
- 가족 행사용 5곡 시리즈를 모두 같은 Persona로
